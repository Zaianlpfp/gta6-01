# Solmar Bay — an open-world crime game

A complete GTA-style open world that runs offline in a desktop browser from
static files: a sun-soaked coastal city to explore on foot and by car, traffic
and pedestrians, cars to steal and drive, a wanted level with police, heli and
roadblocks responding to it, 8 story missions with a crew, combat, shops,
radio, a HUD with minimap, and a save system.

## Play

Serve `game/` with any static server and open `game/index.html`, or run:

```sh
node serve.ts
# then open http://localhost:8080
```

No network request, no build step. All art, code and sound are original —
nothing from any commercial game.

## Controls

- **WASD / arrows** — drive / walk, **Space** — brake / handbrake
- **E** — enter / exit car, **F** — shop, **1–5** — weapons, **R** — reload
- **Q** — radio station, **M** — map, **P** — pause, **Esc** — close

## The city

Solmar Bay has 9 districts — Pelican Marina, Palmetto Heights, Bayline Docks,
Coral Strand, Downtown, Deco Row, Old Mercado, Neon Mile and Keystone Field —
with a bank heist storyline: Jax, Lucia and Mara run jobs across the city while
the Solmar PD, led by the GULL-1 heli, hunts them down. Earn cash and REP,
rank up from Street Kid to Kingpin, and survive the Saltjack standoff.
